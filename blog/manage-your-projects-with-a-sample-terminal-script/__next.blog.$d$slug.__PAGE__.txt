3:T1d4a,<h2>Managing Multiple Projects in the Terminal</h2>
<p>This might not seem like a big deal, but if you’re handling multiple projects, opening the file explorer and navigating through different directories every time can be frustrating. And let’s be honest, remembering old project directories can also be a hassle, depending on how you manage your files and folders as a developer.</p>
<p>To solve this problem, I wrote a simple terminal tool that allows me to <strong>quickly open projects in VS Code, search for projects, and manage project lists effortlessly</strong>—all from the command line.</p>
<p><img src="/img/script-project.png" alt=""></p>
<h2>How It Works</h2>
<p>This script keeps a list of your project directories in a <code>.projects_list</code> file inside your home directory. It allows you to:</p>
<p>✅ <strong>Add a single project</strong> to the list<br/>
✅ <strong>Add a directory containing multiple projects</strong><br/>
✅ <strong>Search for projects by name</strong><br/>
✅ <strong>List all saved projects</strong><br/>
✅ <strong>Delete multiple projects from the list</strong><br/>
✅ <strong>Open a selected project in VS Code</strong></p>
<p>Here’s the full script:</p>
<pre><code class="language-bash">#!/bin/zsh
PROJECTS_FILE=&quot;$HOME/.projects_list&quot;

touch &quot;$PROJECTS_FILE&quot;

ascii_art=&quot;
  _   _               _     _        ____
 | \ | | _____      _| |__ (_) ___  |  _ \  _____   __
 |  \| |/ _ \ \ /\ / / &#39;_ \| |/ _ \ | | | |/ _ \ \ / /
 | |\  |  __/\ V  V /| |_) | |  __/_| |_| |  __/\ V /
 |_| \_|\___| \_/\_/ |_.__/|_|\___(_)____/ \___| \_/
&quot;

echo &quot;$ascii_art&quot;

clean_project_list() {
    sed -i &#39;&#39; &#39;/^$/d&#39; &quot;$PROJECTS_FILE&quot;
}

list_projects() {
    clean_project_list
    if [[ ! -s &quot;$PROJECTS_FILE&quot; ]]; then
        echo &quot;No projects found.&quot;
        exit 0
    fi
    awk -F &#39;/&#39; &#39;{print NR, $NF}&#39; &quot;$PROJECTS_FILE&quot;
}

open_project() {
    clean_project_list
    if [[ ! -s &quot;$PROJECTS_FILE&quot; ]]; then
        echo &quot;No projects found.&quot;
        exit 0
    fi

    echo &quot;Select a project to open in VSCode:&quot;
    awk &#39;{print NR, $0}&#39; &quot;$PROJECTS_FILE&quot; | awk -F &#39;/&#39; &#39;{print $1, $NF}&#39;

    echo -n &quot;Enter project number to open (0 to cancel): &quot;
    read selection

    if [[ &quot;$selection&quot; == &quot;0&quot; ]]; then
        echo &quot;Canceled.&quot;
        exit 0
    fi

    project_path=$(sed -n &quot;${selection}p&quot; &quot;$PROJECTS_FILE&quot;)
    if [[ -n &quot;$project_path&quot; ]]; then
        echo &quot;Opening $project_path...&quot;
        code &quot;$project_path&quot;
    else
        echo &quot;Invalid selection.&quot;
    fi
}

add_project() {
    if [[ -n &quot;$1&quot; ]]; then
        project_path=&quot;$1&quot;
    else
        echo -n &quot;Enter project directory: &quot;
        read project_path
    fi

    if [[ -d &quot;$project_path&quot; ]]; then
        echo &quot;$project_path&quot; &gt;&gt; &quot;$PROJECTS_FILE&quot;
        echo &quot;Project added: $project_path&quot;
    else
        echo &quot;Invalid directory.&quot;
    fi
}

add_directory() {
    if [[ -n &quot;$1&quot; ]]; then
        dir_path=&quot;$1&quot;
    else
        echo -n &quot;Enter project directory: &quot;
        read dir_path
    fi

    if [[ -d &quot;$dir_path&quot; ]]; then
        find &quot;$dir_path&quot; -mindepth 1 -maxdepth 1 -type d &gt;&gt; &quot;$PROJECTS_FILE&quot;
        echo &quot;Projects from directory added.&quot;
    else
        echo &quot;Invalid directory.&quot;
    fi
}

search_projects() {
    clean_project_list
    echo -n &quot;Enter search term: &quot;
    read search_term

    matches=$(grep -i &quot;$search_term&quot; &quot;$PROJECTS_FILE&quot;)

    if [[ -z &quot;$matches&quot; ]]; then
        echo &quot;No matching projects found.&quot;
        exit 0
    fi

    echo &quot;Search results:&quot;
    echo &quot;$matches&quot; | awk -F &#39;/&#39; &#39;{print NR, $NF}&#39;
    echo -n &quot;Enter project number to open (0 to cancel): &quot;
    read selection

    if [[ &quot;$selection&quot; == &quot;0&quot; ]]; then
        echo &quot;Canceled.&quot;
        exit 0
    fi

    project_path=$(echo &quot;$matches&quot; | sed -n &quot;${selection}p&quot;)
    if [[ -n &quot;$project_path&quot; ]]; then
        echo &quot;Opening $project_path...&quot;
        code &quot;$project_path&quot;
    else
        echo &quot;Invalid selection.&quot;
    fi
}

delete_projects() {
    clean_project_list
    list_projects
    echo -n &quot;Enter project numbers to delete (comma-separated): &quot;
    read selections

    new_list=$(awk -v selections=&quot;$selections&quot; &#39;BEGIN {
        split(selections, nums, &quot;,&quot;);
        for (i in nums) remove[nums[i]] = 1;
    }
    !remove[NR]&#39; &quot;$PROJECTS_FILE&quot;)

    echo &quot;$new_list&quot; &gt; &quot;$PROJECTS_FILE&quot;
    echo &quot;Projects deleted.&quot;
}

help_menu() {
    echo &quot;
Usage: p [options]
Options:
  -a &lt;path&gt;    Add a single project folder
  -ad &lt;path&gt;   Add a directory containing multiple projects
  -s &lt;query&gt;   Search projects
  -l           List all projects
  -d           Delete a project from the list
  -h           Show this help message
&quot;
}

case &quot;$1&quot; in
    -a) shift; add_project &quot;$@&quot; ;;
    -ad) shift; add_directory &quot;$@&quot; ;;
    -s) search_projects ;;
    -l) list_projects ;;
    -d) delete_projects ;;
    -h) help_menu ;;
    *) open_project ;;
esac
</code></pre>

<h3>Instructions for macOS/Linux</h3>
<p>To make the script work globally from any directory in your terminal, follow these steps:</p>
<p>Step 1: Save the Script</p>
<ol>
<li>Copy the script provided above into a file named <code>project_manager.sh</code>.</li>
<li>Save the file in a directory, for example <code>~/scripts</code>.</li>
</ol>
<p>Step 2: Make the Script Executable</p>
<ol>
<li>Open your terminal.</li>
<li>Navigate to the directory where you saved the script. For example:</li>
</ol>
<pre><code class="language-sh">&gt; cd ~/scripts
</code></pre>
<ol start="3">
<li>Make the script executable by running the following command:</li>
</ol>
<pre><code class="language-sh">&gt; chmod +x project_manager.sh
</code></pre>
<p>Step 3: Create a Symlink to Make it Accessible Globally
To run the script from anywhere, create a symlink to a directory that’s already in your $PATH.</p>
<ol>
<li>Run this command to create the symlink:</li>
</ol>
<pre><code class="language-sh">&gt; ln -s ~/scripts/project_manager.sh /usr/local/bin/p
</code></pre>
<h2>Conclusion</h2>
<p>This simple script saves a lot of time when managing multiple projects. Instead of manually navigating through directories, I can quickly open any project from the terminal in just a few keystrokes. If you work with multiple projects frequently, I highly recommend setting this up!</p>
<p>Try it out, and let me know if you have any suggestions to improve it!</p>
