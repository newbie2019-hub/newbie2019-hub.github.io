15:T7f9,<h4>React Strict Mode</h4>
<p>React&#39;s Strict Mode is a tool that helps developers write better and more robust React applications. It is a development mode-only feature, meaning it does not affect the production build of your application.</p>
<p>Strict Mode activates additional checks and warnings for its descendants, helping to identify potential problems early in the development cycle. These checks include:</p>
<ul>
<li>Identifying Unsafe Lifecycles: It flags components with deprecated or unsafe lifecycle methods.</li>
<li>Highlighting Side Effects: Strict Mode helps detect unexpected side effects in code, such as side effects in useEffect or other lifecycle methods.</li>
<li>Enforcing Best Practices: It enforces best practices like avoiding usage of legacy React features.</li>
<li>Simulating Mount/Unmount Cycles: It intentionally mounts and unmounts components twice to surface issues in cleanup logic.</li>
</ul>
<p>Example for this is an event listener which you forgot to remove afterwards. The output of the code below will trigger the addEventListener twice and whenever you click within the dom it will output twice.</p>
<pre><code class="language-js">import { useEffect } from &#39;react&#39;

export function Home() {
  const handleClick = () =&gt; {
    console.log(&#39;click&#39;)
  }

  useEffect(() =&gt; {
    document.addEventListener(&#39;click&#39;, handleClick)
  }, [])

  return (
    &lt;&gt;
      &lt;p&gt;Home&lt;/p&gt;
    &lt;/&gt;
  )
}
</code></pre>
<p>This is an example of why React Strict Mode is important for development. To fix this issue
we just need to remove the event listener upon unmount of the component. The useEffect will look like this.</p>
<pre><code class="language-js">useEffect(() =&gt; {
  document.addEventListener(&#39;click&#39;, handleClick)

  () =&gt; document.removeEventListener(&#39;click&#39;, handleClick)
}, [])
</code></pre>
<p>You can check more information by going through their <a href="https://react.dev/reference/react/StrictMode">documentation</a>.</p>
